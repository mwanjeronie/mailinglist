# Mwanje Ronnie — Events Newsletter

A minimal static landing page that directs visitors to subscribe to the events newsletter on [Luma](https://luma.com/winjo).

## Stack

- [Next.js 16](https://nextjs.org) — static site generation
- [Tailwind CSS](https://tailwindcss.com) — styling
- [Vercel](https://vercel.com) — hosting

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
vercel --prod
```
